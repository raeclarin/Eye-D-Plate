Welcome to Eye-D-Plate!

Software required: Node.js, NPM, Svelte

To run:
- Navigate to the folder.
- Enter this command: 'cd eyedplate' to navigate to the directory
- Enter this command: 'npm install' to audit and get the current packages 
- Enter this command: 'npm run dev' to run the website
